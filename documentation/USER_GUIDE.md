# Руководство пользователя

## Как забронировать столик
1. Зарегистрируйтесь или войдите
2. Перейдите в "Бронирование"
3. Выберите дату, время, количество гостей
4. Подтвердите бронирование

## Личный кабинет
- Просмотр истории бронирований
- Отмена бронирований
- Редактирование профиля

## Администратор
- Управление столиками через /admin/
- Просмотр всех бронирований
- Управление пользователями
